# Contributing

Keep this a lightweight skill. Improve a demonstrated research or drafting decision with concise instructions. Describe the user request, current problem and expected behavior in your issue or pull request.

Use synthetic examples. Do not include prospect lists, private client information, credentials or live contact details. Check that source claims are supported and local documentation links resolve.

The package is self-contained in `skills/ai-client-hunter/`. Keep its name/frontmatter valid and its agent metadata consistent. Installation should discover exactly one skill. Do not add scripts, dependencies or a rigid data pipeline without a demonstrated need and an agreed scope.

Contributions are provided under the repository's MIT license.
