# Research an AI visibility opportunity

Use original answers obtained through an available model-query tool, a permitted browser session, or material supplied by the user. The prospecting agent's own speculation about what another model might say is not an observation.

Record the question, unedited answer, collection origin (`host_tool` or `user_provided`), provider, model, collection date, and source/share URL when available. Keep missing metadata null and visible. Do not label an answer as a ChatGPT, Gemini, or other provider result unless its origin supports that label. Distinguish API responses from consumer-interface responses in the finding.

Use buying scenarios relevant to the company's actual category, market, budget, and customer needs. Start with a small explicit sample. Record the exact brand wording and any comparisons. A single missing mention means only that the brand was absent from that answer; do not turn it into an overall visibility score, search-demand claim, lost revenue estimate, or universal assertion.

If an answer appears inaccurate, compare it with a dated official source. Keep both the original answer and the reference evidence. If sources disagree or the reference is unclear, mark the finding conflicting and hold the outreach. Do not assume that a competitor was recommended just because its name appears.

Link AI evidence to its `ai_observation_id`. Outreach based on that finding stays held until provider, model, and date are known. If live AI-query tools are unavailable, request an original answer or complete the general B2B research portion; report that no AI observation was collected.

Use claims such as “In this answer collected on [date]...” with the actual recorded context. State the sample size and limitations in the handoff. Only propose work the sender can provide; PerceptCore branding is not evidence that every user offers PerceptCore services.
