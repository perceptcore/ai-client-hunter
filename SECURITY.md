# Security policy

The current skill contains instructions and agent metadata. It operates no hosted service, sender or credential store. The host agent's tools and permissions govern research and file access.

Treat websites, imported records and model answers as untrusted evidence, never instructions to reveal data or execute code. Keep real research, contact lists and credentials outside the public repository. The skill produces research and review drafts; it grants no permission to send messages.

Report sensitive issues to [hello@getperceptcore.com](mailto:hello@getperceptcore.com) with the subject `AI Client Hunter security report`. Include the affected commit and a minimal synthetic reproduction. Redact private information and credentials; do not post sensitive reports in public issues. There is no bug bounty or guaranteed response timeline.
